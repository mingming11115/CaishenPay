# 财神记薪

原生 iPhone + Apple Watch 记薪应用，最低支持 iOS 17 / watchOS 10。

## 开始使用

1. 用 Xcode 打开 `CaishenPay.xcodeproj`，选择 `CaishenPay` Scheme 和 iPhone 模拟器运行。
2. 首次打开填写月薪、加班折算标准小时和倍率；月工作日根据中国大陆节假日及调休日历自动统计。
3. 首页点击「今日上班」记录一天出勤，不启动计时；日收入为月薪除以当月工作日数。同日不重复记账。
4. 点击「开始加班」，确认工作日、休息日或节假日类型。默认倍率分别为 1.5 / 2 / 3，可在设置中调整。
5. 「加班」页可以核对、补录、修正或删除工作记录。「账本」按工资所属月份保存应收、未到账余额及每笔到账。
6. 配对手表打开「财神记薪」，同步手机工资规则后可查看今日收入、时长，开始和结束加班。普通上班在手机操作。

真机安装：在两个 target 的 Signing & Capabilities 选择自己的 Apple Developer Team，再选择已连接的 iPhone 运行。手表需要与该 iPhone 配对。完整命令、bundle ID 调整、工程重新生成方法见 [README-build.md](README-build.md)。

## 计薪与记账口径

- 正常日收入 = 月薪 ÷ 当月工作日数；加班基准时薪再除以每日标准小时（默认 8 小时，可修改）。
- 今日估算 = 当日出勤收入 + 各类加班时间 × 对应时薪和倍率。正常出勤与工时无关；加班中途休息请结束计时，回来后重新开始。旧版计时记录保留原金额，并明确标注，不显示为一天出勤。
- 月工资估算 = 整月 base + 本月已记录的加班。税费、请假、缺勤、补发及月中调薪的折算，直接调整该月应收。月中有新规则时，估算使用截至当前或该月末最新生效的 base。
- 每条记录保存当时的工资和班次规则，后续改设置不会重算历史记录。保存已生效规则时会先结束正在进行的计时。
- 工作日/休息日/节假日由你逐次选择，避免把调休工作日误当周末。跨日加班拆分后请逐日确认类型。
- 所有金额按分保存；应收与到账相互独立。支持部分到账、多笔到账、直接输入剩余未到账，以及多到账提示。
- 两台设备离线产生的重叠记录会提示冲突，冲突记录暂不计入收入；请在手机核对修正。

## 数据与同步

数据保存在设备 Application Support 的 `CaishenPay/pay-state-v1.json`，每次修改原子写入。计时以开始和结束时间计算，应用进入后台或重新打开后仍可恢复。没有服务器、登录、银行接口或外部数据上传。

手机为设置与账本的来源，手表保留离线加班记录，连接恢复后通过 WatchConnectivity 合并并确认。手表中「待同步」表示记录仍保存在手表。系统决定后台通信时机，并不保证两端每秒刷新同步。

请勿通过卸载应用清理故障，卸载可能丢失本地数据；当前版本没有独立备份导入/导出功能。如无法读取数据，会保留原文件并停止覆盖。

## 演示与验证

Xcode Scheme 的 Run → Arguments 中添加 `--demo` 可查看示例页面。演示数据只在内存中，不覆盖真实工资，不与其他设备同步。正常启动没有预置月薪或到账。

核心测试位于 `Packages/WorkPayCore/Tests`，覆盖金额精度、三个加班倍率、午休、跨午夜、跨夜班、遗忘结束计时、规则历史快照、重叠处理、离线合并、准确确认和数据编码。

```sh
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcrun swift test --package-path Packages/WorkPayCore
```

两端构建、模拟器验证及真机签名方法见 [构建说明](README-build.md)。首次上真机后需检查配对通信和离线重连；工程未上传到 App Store 或 TestFlight。

## 按天出勤（2026-10 更新）

首页「今日上班」一次记录当天出勤，不创建计时器；当天只能记录一次，工作记录可补录、修正和删除。正常日收入为月薪除以该月中国大陆工作日数，与工时无关。加班继续单独计时，新加班记录用所在月份的工作日数折算时薪。旧计时记录和旧工资快照保留原算法。

日历内置国务院办公厅公布的 2026 年节假日及调休安排，离线可用。工作日排除公布的假期，加入周末补班；目前未提供联网年度更新，其他年份会提示缺少日历并阻止新建按天记录，不会静默按周一至周五代算。年度数据在 `Packages/WorkPayCore/Sources/WorkPayCore/MainlandWorkCalendar.swift` 维护。

来源：[国务院办公厅关于2026年部分节假日安排的通知](https://www.beijing.gov.cn/fuwu/bmfw/sy/jrts/202511/t20251104_4258838.html)。
