# 独立加班费基数

用户要求正常工资与加班费使用不同基数。设置中增加“加班费基数与月薪相同”开关，默认开启；关闭后填写“加班费月基数（元）”，并预览加班基准时薪。

沿用 SwiftUI、WorkPayCore 和现有同步方式。增加可选 `PaySettings.overtimeMonthlyBase`；未填写时跟随 `monthlyBase`。正常出勤、旧版正常计时仍使用月薪；加班汇总、月估算使用独立基数。计薪天数仍采用已有的当月工作日数，倍率和每日标准小时保持原设置。

方案比较：可选独立基数可以兼容旧 JSON，并明确表示“跟随月薪”；重复保存一份月薪容易在调薪后失去跟随关系；用倍率变相折算不能清楚表示工资规则。因此采用可选独立基数。

旧文件无此字段时保持原算法。每条记录继续保存完整规则快照，跨日拆分、落盘和手机/手表同步保留独立基数，后续修改规则不重算历史。输入校验沿用月薪的非负金额、金额上限和折算时薪上限。

本次不修改节假日日历、计薪天数口径、已有工程签名配置或发布安装包。通过核心测试和两端模拟器构建验证。
